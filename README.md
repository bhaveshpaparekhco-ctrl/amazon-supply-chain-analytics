# Amazon Supply Chain & Operations Analytics Dashboard

## Project Overview

This project is an end-to-end Business Intelligence solution built using Power BI, Excel, Power Query, and DAX. The dashboard simulates the analytical ecosystem of a large e-commerce company such as Amazon by integrating Sales, Inventory, Logistics, Returns, and Customer Analytics into a single reporting framework.

The objective of this project is to transform raw operational data into actionable business insights that support data-driven decision-making across supply chain and business operations.

---

## Business Problem

Large e-commerce businesses generate massive volumes of transactional and operational data every day. Decision-makers need a centralized analytics platform to monitor:

* Revenue and profitability
* Inventory health
* Warehouse performance
* Logistics efficiency
* Product returns
* Customer behavior

This project addresses these challenges by providing interactive dashboards and KPI-driven insights.

* Customers

### 3. Data Modeling

Implemented a Star Schema model with:

* Fact Tables

  * Products
  * Date Table

### 4. KPI Development

Created business-focused measures using DAX.

### 5. Dashboard Development

Built multiple interactive dashboards for operational and strategic analysis.

# Key Business Insights

### Sales Insights

* Revenue is concentrated within a few high-performing product categories.
* Certain regions contribute significantly more to overall sales performance.

### Inventory Insights

* Low-stock products can be identified proactively for replenishment planning.
* Inventory value is concentrated in specific categories and warehouses.

### Logistics Insights

* Delivery performance varies across courier partners.
* Shipping modes influence fulfillment efficiency and customer experience.

### Returns Insights

* Product defects and operational issues contribute significantly to return volumes.
* Returns analytics can help reduce refund costs and improve customer satisfaction.
