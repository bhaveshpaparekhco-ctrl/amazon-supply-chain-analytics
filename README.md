# Amazon Supply Chain & Operations Analytics Dashboard

## Project Overview
Built an end-to-end business intelligence solution using Power BI, Excel, Power Query, and DAX.

## Key Areas Covered
- Sales Analytics
- Inventory Management
- Logistics Performance
- Returns Analysis
- Customer Insights

## Tools Used
- Power BI
- Excel
- Power Query
- DAX
